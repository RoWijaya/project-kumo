# ☁️ Project Kumo

A secure, minimalist web-based note-taking application built with PHP and MySQL.

## Goals

- Learn web development
- Learn software engineering
- Learn database design
- Learn cybersecurity
- Build a real-world portfolio project

## Planned Features

- User Authentication
- Create, Edit, Delete Notes
- Search Notes
- Responsive Design

## Future Features

- Expense Manager
- Mobile App
- Handwritten Notes
- Cloud Synchronization
- End-to-End Encryption
