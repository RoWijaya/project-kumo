# ☁️ Project Kumo

Kumo is a minimalist productivity workspace designed around **Clouds**.

Instead of organizing information into separate notes and reminders, each Cloud contains everything related to one part of your life.

Current Progress:
- ✅ Login Page
- ✅ Register Page
- ⏳ Dashboard
- ⏳ Cloud Workspace
- ⏳ AI Assistant (Silver Lining)

## Built With

- HTML5
- CSS3
- JavaScript
